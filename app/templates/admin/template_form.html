Unggah Template Sertifikat Baru

Setelah diunggah, Anda akan diarahkan ke halaman kalibrasi untuk mengecek/mengatur posisi Nama, NIM, Fakultas, Universitas, tanggal terbit, nomor sertifikat, dan QR code di atas desain ini.

Desain dengan SEMUA field terisi teks contoh (Nama, NIM, Fakultas, Universitas) — isi apa saja asal beda tiap field. Tanggal terbit TIDAK perlu diisi khusus di sini — biarkan seperti desain aslinya, karena tidak lagi dideteksi otomatis (lihat catatan di bawah).

File YANG SAMA PERSIS seperti di atas — HANYA hapus teks Nama/NIM/Fakultas/Universitas. Judul, kalimat sambutan, paragraf baku, tanggal terbit, dan nama/jabatan penandatangan JANGAN dihapus, biarkan tetap ada di kedua file.

Tentang tanggal terbit: sengaja tidak lagi dideteksi/diganti otomatis — dianggap bagian tetap dari desain (seperti teks statis lainnya). Kalau tanggalnya beda tiap periode, cukup ganti/unggah template baru saja. Kalau tetap ingin tanggal dinamis mengikuti periode magang secara otomatis, itu masih bisa diaktifkan manual lewat halaman Kalibrasi setelah upload.
Kesalahan paling umum: menghapus SEMUA teks (termasuk judul "SERTIFIKAT", kalimat sambutan, paragraf baku, nama penandatangan) di versi polos. Itu keliru — bagian-bagian itu tidak pernah berubah per peserta, jadi harus tetap ada di kedua file. Yang boleh dikosongkan cuma area yang memang beda tiap peserta.
Kedua file wajib berasal dari file sumber yang sama (cuma beda teksnya) supaya elemen dekoratif lain tidak ikut goyah posisinya saat dibandingkan.

Unggah desain dengan area Nama/NIM/Fakultas/Universitas/tanggal dikosongkan (polos) — semua posisi teks diatur manual di halaman kalibrasi berikutnya lewat drag/angka + pratinjau langsung.

Kalau desain masih ada tulisan placeholder seperti "Nama Mahasiswa"/"NIM", sistem akan mencoba mendeteksi & membersihkan posisinya otomatis — tapi ini cuma bonus, tidak wajib.

Font Kustom (opsional)

Kalau diunggah, font ini menggantikan font bawaan pada sertifikat yang digenerate. Boleh isi sebagian saja — yang dikosongkan tetap pakai font bawaan (Pinyon Script untuk nama, Cardo untuk identitas & tanggal).

Untuk nama peserta, mis. "Muhammad Naufal Nashir".

Untuk baris NIM, Fakultas, dan Universitas — termasuk label ("NIM :") maupun isiannya.

Untuk tanggal terbit sertifikat, mis. "30 Agustus 2026" — otomatis mengikuti tanggal periode magang, jadi tidak perlu ganti template tiap periode berbeda.

3 hal yang perlu diperhatikan
  • Resolusi tinggi. Ekspor dari Canva/Illustrator sebagai "HD" atau lebar ≥ 2400px (setara 300 DPI), format PDF paling aman.
  • Area teks kosong (versi polos). Pastikan bagian Nama/NIM/Fakultas/Universitas memang kosong — teks peserta akan ditempel di atasnya nanti. Tanggal terbit tidak perlu dikosongkan.
  • Rasio A4 landscape. Lebar : tinggi ≈ 1.41 : 1, supaya konsisten dengan sertifikat lain.
